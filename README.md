# BaJuca

Quebra-cuca com Juma & Bart: puzzles de raciocínio para crianças, da **Jubart**.

- **Canteiros**: um cachorro em cada cor, um por linha e coluna, sem ninguém se encostar.
- **Cercadinhos**: cerque cada cachorro com o número exato de casas.

Jogue em https://lucasnatanfc.github.io/bajuca/ e instale como app pelo navegador do celular.
